# ARDSWC Open Data Loader 水保署開放資料載入

作者：黃敏郎（GitHub: [yoshihuang](https://github.com/yoshihuang)）

QGIS plugin that loads the open map data of Taiwan's **Agency of Rural Development and Soil and
Water Conservation** (農業部農村發展及水土保持署, ARDSWC) for the current map view.

在 QGIS 中直接介接[水保署資料平台的開放資料 API](https://data.ardswc.gov.tw/Data/OpenData/Api)：
勾選資料項目後，移動或縮放地圖時，套件會自動下載畫面範圍內的資料，以記憶體暫存圖層顯示；
可一鍵把所有暫存圖層匯出到指定資料夾，也可以把選取的 UAV 正射影像加入成影像圖層。

## 功能

- 21 項開放資料可複選，分成「土石流與大規模崩塌」「崩塌與集水區」「山坡地與水土保持」
  「農村與農路」「影像與災害紀錄」五組，面板顯示每項資料的筆數與下載進度。
- 地圖移動或縮放停止約 0.7 秒後自動更新；新範圍會取消舊的下載，同時最多 6 個連線，
  解碼與合併在背景執行，不會卡住 QGIS。已下載的圖磚與目錄會快取，來回平移不重抓。
- **向量圖磚（MVT）轉成暫存圖層**：依畫面大小自動選用 z14／z13／z12 圖磚（最多 48 張），
  解碼後依 `gid`（農路用 `newcode`）把被圖磚切開的同一個圖徵合併回一筆。
  範圍太大時提示放大地圖，可勾選「忽略建議範圍」放寬到 400 張。
- 點位資料（災害照片、重大土石災情報告）與 UAV 影像目錄：整份下載一次（快取 15 分鐘），
  再依畫面範圍篩選。
- 照片點位以箭頭表示拍攝方向，滑鼠停留（地圖提示）可預覽照片；災情報告附 PDF 連結。
- UAV 正射影像：在「UAV 空拍正射影像範圍」圖層選取影像範圍，按「加入選取的 UAV 正射影像」
  即加入 XYZ 影像圖層（一次最多 10 幅，最小縮放層級依影像自動設定）。
- 一鍵匯出：GeoPackage（單一檔或每層一檔）、Shapefile、GeoJSON；座標可選 WGS84、TWD97 TM2
  121／119 或專案座標；樣式一併保存，並產生「資料來源說明.txt」。
- 支援 QGIS 3.34 以上版本，以及 QGIS 4（Qt6）。不需要另外安裝 Python 套件。

| 農村與農路 | 農村再生計畫社區、農路 | MVT |

## 使用須知

- 向量圖磚的幾何精度依層級而定：z14 約 0.6 m、z12 約 2.4 m；低層級圖磚會簡化幾何，
  所以套件只用 z12 以上。
- 合併後的圖徵只涵蓋已下載圖磚的範圍；畫面外的部分不會出現。
- 部分圖層屬性內另有座標欄位（如 `epsg4326_x`），可能與圖磚幾何略有差異，以圖磚幾何為準。
- 影像平台 API 每類最多回傳 1,000 張照片。

## 資料授權

資料來源為農業部農村發展及水土保持署資料平台，依
[水保署政府網站資料開放宣告](https://www.ardswc.gov.tw/Home/WebService/GWOIA?id=af86de76394f4df28ecbec7e8592b6fa)
以無償、非專屬方式提供，使用時請註明出處。部分經特別聲明須經同意的照片、影音不在授權範圍內，
本套件只載入照片位置與說明，照片以連結方式顯示。本套件只介接公開 API，不重新散布資料。

## 開發與測試

```
ardswc_loader/   # 套件本體（上架時只壓縮這個資料夾）
test/            # 離線整合測試：本機假伺服器 + 真實 API 樣本
```

```bash
pip install mapbox-vector-tile      # 只有測試需要（產生測試用圖磚）
QT_QPA_PLATFORM=offscreen python3 test/test_plugin.py
```
